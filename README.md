# Astel Antony Portfolio

A calm, proof-led portfolio for Astel Antony, focused on Generative AI, cybersecurity, projects, experience, and contact details.

This repository includes a static `index.html` version so the portfolio can be viewed without running a local development server.

## View

Open `index.html` in the repository, or enable GitHub Pages from the repository settings using the `main` branch and root folder.
